## 已执行的质量闸门

构建期用脚本机械校验(脚本不入库,位于会话临时目录):

- **来源核实闸门** — 65 条链接逐条实测:63 条 HTTP 200,2 条(openai.com,拒爬)经搜索索引确认标题与内容匹配。凭记忆生成的地址一律不采用;核实失败的一律不写入(例如一条 Gary Marcus 文章地址实测 404,已剔除并改用其他已核实批评来源)。
- **引用逐字核对** — 21 处直接引用全部与 situational-awareness.ai 原文逐字比对通过,无改写、无幻觉引文;两处曾因嵌套引号被改动,已修正。
- **引用配额与相邻句护栏** — 每章 ≤4 处(红线为 8),每处 ≤1 句;同章任两处引用在原文中的字符距离均 ≥260,无拼接还原风险。
- **引用包裹比** — 每处引用的前后原创分析为引用本身的 2.3–14 倍,全部满足"分析长于引用"。
- **记分牌一致性** — 各章记分牌行数与该章 `.audit` 卡片数逐章相等;第 7 章总记分牌 29 行与全书 29 张卡片一一对应。
- **无残留标记** — 全书无 `.slot`、无「来源槽」。
- **HTML 与链接** — 全部文件标签平衡;站内相对链接全部可达。
- **图表色彩** — 全部内联 SVG 的描边与填充改用 CSS 变量(经 `style` 属性,presentation attribute 不支持 `var()`),符合"颜色一律取 CSS 变量"的技术约定;浏览器实测解析正常。
- **响应式通读** — 15 个页面在 1280px 与 375px 下实测均无横向滚动。窄屏曾因 `.term{white-space:nowrap}` 撑破 5 个页面,已加 560px 断点修复并复测。
